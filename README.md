# Cleveland RP loading screen player

The YouTube player page the Cleveland RP loading screen embeds: https://gholsona171.github.io/crp-loadscreen-player/

YouTube won't play inside FiveM's loading screen page, so the player lives here on https. The loading screen sends it
the playlist and the next / previous / mute commands. The links themselves stay in the server's `crp_loadscreen/playlist.js`.
